# Target & Habit Hub

Telegram bot for NEET aspirants to set, track and sustain study targets and habits with one-tap check-ins, timezone-aware reminders, streaks and weekly reports.

Spec: [`docs/blueprint.md`](docs/blueprint.md).

Built on [agnt-gm.ai](https://agnt-gm.ai). The whole bot is built and refined here as pull requests across successive build passes.
